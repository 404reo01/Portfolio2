# Portfolio de Rayan, version RPG

Un personnage, des quêtes, un terminal caché et un cheat code (cherche bien).

**Site :** https://portfolio-rayan-elouazzani.netlify.app/

## Ce qu'il y a dedans

- **Sélection du personnage** : expériences et compétences.
- **Lore** : le parcours, du génie électrique jusqu'au MSc.
- **Quêtes** : les projets, avec un CV qu'on parcourt en SSH depuis son propre terminal.
- **Terminal** : appuie sur `/` n'importe où sur la page, puis tape `help`.

## Stack

React 19 · Vite · Tailwind CSS 4 · Framer Motion · Matter.js

## Lancer en local

```bash
npm install
npm run dev
```
